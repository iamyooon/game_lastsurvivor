# 마지막 사람 — 프로토타입

멸망 후 1년, 가족과 헤어진 아이(재희 또는 재헌)가 하루에 한 가지 생존 기술을 익히며 엄마 아빠와 형제를 찾아가는 2D 도트 게임.

## ▶ 바로 플레이하기
**https://iamyooon.github.io/game_lastsurvivor/**

설치나 다운로드 없이 브라우저에서 바로 플레이할 수 있어요. PC와 휴대폰 모두 지원합니다.
- PC: WASD·방향키로 이동, Space·숫자키로 행동, P로 일시정지
- 휴대폰: 화면을 눌러 이동, 주인공 주변에 뜨는 아이콘을 눌러 행동
- 캐릭터: 재희(딸)·재헌(아들). 고른 캐릭터 이름이 이야기 속 주인공 이름이 됨 (성은 윤)

- `index.html` 한 파일로 동작 (그래픽·음악·효과음 모두 코드로 생성)
- 배포: claude.ai 아티팩트 "마지막 사람 — 프로토타입"
- 저장소: https://github.com/iamyooon/game_lastsurvivor

## 일주일 구성 (1부)
1. 물이 탁해졌다 — 식수 만들기
2. 폭풍이 온다 — 쉼터와 체온
3. 불씨가 꺼졌다 — 불 피우기
4. 배가 고프다 — 먹을 것 구하기
5. 다쳤다 — 응급처치
6. 북쪽은 어디일까 — 방향 찾기
7. 누군가에게 — 구조 신호 (라디오 응답, 1부 엔딩)

## 2주차 구성 (2부 · 강 하구로)
8. 끈이 필요하다 — 끈과 매듭
9. 짐을 꾸리다 — 장거리 이동 준비 (배낭에 꾸린 것만 가지고 떠남)
10. 산이 무너졌다 — 동굴 안전: 횃불, 갈림길 표시, 나쁜 공기, 낙석 (새 지도: 동굴)
11. 하늘을 읽다 — 날씨 읽기: 구름·햇무리·제비·연기, 비 피할 자리 (새 지도: 강 골짜기)
12. 배를 엮다 — 송진과 숯으로 역청, 나룻배 「수아호」 고치기, 노 만들기
13. 물을 건너다 — 여울 고르기, 짐 묶기, 낮게 앉아 상류로 비스듬히 젓기
14. 선착장 — 연기 신호, 낯선 사람 안전하게 만나기 (2부 엔딩)

## 폴더

- 아티팩트를 다시 올릴 때 버전 라벨을 커밋 메시지와 맞춘다.
- 커밋하면 GitHub(main)에도 바로 push한다.

## 이야기 방향
- 그날 정류장에서 가족이 흩어짐. 아빠는 먼저 북쪽 대피소로, 주인공은 엄마와 형제의 손을 놓침
- 1부: 혼자 살아남기 → 라디오로 아빠가 살아 있음을 알게 됨
- 2부: 아빠의 흔적을 따라 강 하구로 → 선착장에서 엄마의 소식
- 3부(예정): 엄마를 찾고 둘이 함께 다님 → 협동 퍼즐
- 이후: 형제를 찾아 셋, 그리고 북쪽의 아빠에게

## 협동 퍼즐 설계 메모 (3부~)
- 동료를 찾으면 같이 다니며, 혼자서는 못 풀고 각자의 특성을 써야만 풀리는 문제가 나온다
- 캐릭터 특성 후보
  - 아이(재희·재헌): 작고 가벼움 — 좁은 틈 통과, 높은 곳에 올려 주면 닿기, 약한 판자 위 건너기
  - 엄마: 키와 힘 — 무거운 것 밀기, 아이 받쳐 올리기, 응급처치·약초 지식
  - 형제(나중): 서로 다른 재주 — 예: 하나는 손재주(라디오·기계), 하나는 눈썰미(흔적·동물 발자국)
- 퍼즐 예시
  - 무너진 창고: 아이가 틈으로 들어가 안쪽 빗장을 풀고, 엄마가 문을 밀어 연다
  - 높은 선반의 약상자: 엄마가 아이를 받쳐 올린다
  - 썩은 다리: 가벼운 아이가 먼저 건너 밧줄을 묶고, 엄마는 밧줄을 잡고 건넌다
  - 두 사람이 동시에 눌러야 하는 수문, 한 사람은 신호를 보고 한 사람은 당기는 도르래
- 조작: 캐릭터 전환(한 명씩 조종) + 따라오기, 또는 상황 메뉴에서 '엄마에게 부탁하기'
