# 마지막 사람 — 프로토타입

멸망 후 1년, 가족과 헤어진 아이(재희 또는 재헌)가 하루에 한 가지 생존 기술을 익히며 엄마 아빠와 형제를 찾아가는 2D 도트 게임.

## ▶ 바로 플레이하기
**https://iamyooon.github.io/game_lastsurvivor/**

설치나 다운로드 없이 브라우저에서 바로 플레이할 수 있어요. PC와 휴대폰 모두 지원합니다.
- PC: WASD·방향키로 이동, Space·숫자키로 행동, P로 일시정지
- 휴대폰: 화면을 눌러 이동, 주인공 주변에 뜨는 아이콘을 눌러 행동
- 캐릭터: 재희(딸)·재헌(아들). 고른 캐릭터 이름이 이야기 속 주인공 이름이 됨 (성은 윤)

- `index.html` 한 파일로 동작 (그래픽·음악·효과음 모두 코드로 생성)
- 배포: claude.ai 아티팩트 "마지막 사람 — 프로토타입"
- 저장소: https://github.com/iamyooon/game_lastsurvivor

## 일주일 구성 (1부)
1. 물이 탁해졌다 — 식수 만들기
2. 폭풍이 온다 — 쉼터와 체온
3. 불씨가 꺼졌다 — 불 피우기
4. 배가 고프다 — 먹을 것 구하기
5. 다쳤다 — 응급처치
6. 북쪽은 어디일까 — 방향 찾기
7. 누군가에게 — 구조 신호 (라디오 응답, 1부 엔딩)

## 2주차 구성 (2부 · 강 하구로)
8. 끈이 필요하다 — 끈과 매듭
9. 짐을 꾸리다 — 장거리 이동 준비 (배낭에 꾸린 것만 가지고 떠남)
10. 산이 무너졌다 — 동굴 안전: 횃불, 갈림길 표시, 나쁜 공기, 낙석 (새 지도: 동굴)
11. 하늘을 읽다 — 날씨 읽기: 구름·햇무리·제비·연기, 비 피할 자리 (새 지도: 강 골짜기)
12. 배를 엮다 — 송진과 숯으로 역청, 나룻배 「수아호」 고치기, 노 만들기
13. 물을 건너다 — 여울 고르기, 짐 묶기, 낮게 앉아 상류로 비스듬히 젓기
14. 선착장 — 연기 신호, 낯선 사람 안전하게 만나기 (2부 엔딩)

## 폴더
- `index.html` — 게임 본체
- `experiments/` — 그래픽 방향을 정할 때 만든 비교 페이지

- 아티팩트를 다시 올릴 때 버전 라벨을 커밋 메시지와 맞춘다.
- 커밋하면 GitHub(main)에도 바로 push한다.

## 이야기 방향
- 그날 정류장에서 가족이 흩어짐. 부모 한 명은 먼저 북쪽 대피소로, 주인공은 남은 부모와 형제의 손을 놓침
- 고른 아이에 따라 찾는 순서가 다름 (대사·기억 물건이 아이에 맞게 바뀜)

| | 재희 (딸) | 재헌 (아들) |
|---|---|---|
| 1~2부 | 아빠의 흔적을 따라 하구로, 2부 끝에 아빠와 만남 | 엄마의 흔적을 따라 하구로, 2부 끝에 엄마와 만남 |
| 3부 | 아빠와 함께 엄마를 찾음 | 엄마와 함께 아빠를 찾음 |
| 4부 | 셋이서 재헌을 찾음 | 셋이서 재희를 찾음 |
| 끝 | 넷이 다시 모임 | 넷이 다시 모임 |

## 협동 퍼즐 설계 메모 (3부~)
같이 다니는 가족마다 잘하는 것이 달라서, 혼자서는 못 풀고 그 사람의 특성을 써야만 풀리는 문제가 나온다.

| 캐릭터 | 특성 | 쓰이는 곳 |
|---|---|---|
| 아빠 | 키가 크고 힘이 셈, 연장을 잘 다룸 | 무거운 바위·문 밀기, 아이 받쳐 올리기, 막힌 길 부수기, 기계 고치기 |
| 엄마 | 꼼꼼한 관찰, 응급처치·약초, 손이 야무짐, 낯선 사람·동물 달래기 | 숨은 표시 찾기, 약 만들기, 매듭·바느질, 사람·개와 마주쳤을 때 |
| 재희 (딸) | 작고 가벼움, 손이 섬세함, 소리와 노래를 잘 기억함 | 좁은 틈 통과, 자물쇠·작은 부품, 오르골 멜로디 퍼즐 |
| 재헌 (아들) | 작고 날렵함, 잘 오르고 멀리 던짐, 겁 없이 먼저 가 봄 | 나무·벽 타고 오르기, 밧줄 던져 걸기, 좁은 굴 먼저 정찰 |

- 퍼즐 예시
  - 무너진 창고: 아이가 틈으로 들어가 안쪽 빗장을 풀고, 아빠가 문을 밀어 연다
  - 썩은 다리: 가벼운 아이가 먼저 건너 밧줄을 묶고, 어른은 밧줄을 잡고 건넌다
  - 높은 선반의 약상자: 아빠가 받쳐 올리고, 엄마가 약초로 약을 만든다
  - 두 사람이 동시에 당겨야 열리는 수문, 신호를 보는 사람과 당기는 사람
- 같은 장소라도 3부에서 아빠와 다니면 힘으로, 엄마와 다니면 다른 길을 찾아서 푸는 식으로 갈래마다 풀이가 다름
- 조작: 캐릭터 전환(한 명씩 조종) + 따라오기, 또는 상황 메뉴에서 '○○에게 부탁하기'
